## 2. 十二个关键问题及核对答案

1. **为什么不能就地更新？** Jacobi 的同一轮必须只读上一轮。就地写回会改变依赖关系，不再是当前算法。
2. **不整除怎么分？** 每轴先分 `n/p`，前 `n%p` 个坐标多一个内部点；起点是 `coord*(n/p)+min(coord,n%p)`。不能假设所有 rank 的子域一样大。
3. **为什么只交换面？** 五/七点模板只访问轴向邻居，不访问角点；因此不需要对角通信。
4. **Sendrecv 的配对是什么？** 一次向低方向发送并从高方向接收，另一次相反；两次使用不同标签。相邻 rank 的切向尺寸一致。
5. **为什么最终残差前还交换一次？** 最后一次更新后的新解尚未作为下一轮旧解交换；直接使用旧 halo 会算错接口残差。
6. **连续误差、离散误差、残差有什么区别？** 连续误差含离散化误差；离散误差与精确离散解比较；残差衡量离散方程的满足程度。它们不能互相替换。
7. **K=1000 是否收敛？** 不一定。它统一性能工作量；收敛由独立数值研究的相对残差阈值判定。
8. **为什么计时取 max 而不是平均？** 分布式迭代的完成受慢 rank 制约。均值会掩盖不平衡和等待；MPI 启动、初始化、最终检查及文件输出不在迭代时间内。
9. **强弱效率如何算？** 强扩展 S=T1/TP、E=S/P；512³ 以 P72 为基准，E72=(T72/TP)/(P/72)。弱扩展 Ew=Tweak1/TweakP，不再除以 P。
10. **混合配比用哪个基准？** 用同一分配、相同总核数的纯 MPI。最终 72 核混合比较来自原单节点配对批次，不能用新的三节点 P72 扩展时间替代其分母。
11. **通信计时是不是纯网络时间？** 不是，阻塞调用还包含等待慢 rank 和调度影响。三个阶段必须取同一最慢总时间 rank，不能把不同 rank 的阶段最大值相加。
12. **144 核慢说明了什么？** 原批次与独立复测都观察到明显等待，但仍不能确定网络、调度、映射或进度机制中的唯一根因。保留数据，并将复测单列。
