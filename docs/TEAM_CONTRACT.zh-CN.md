## 2. 数学和网格约定

- n 为**每边的内部点数**，不是总网格宽度。完整网格为 `(n+2)×(n+2)`；n=16 对应 18×18。
- `i` 是行、`j` 是列，`x=j/(n+1)`、`y=i/(n+1)`，`h=1/(n+1)`。
- 全局内部点的 i、j 范围为 1…n；0 和 n+1 为物理边界。
- 一轮统一使用旧数组的上下左右四点均值；整轮完成后交换 old/new。
- 数学式：`new[i,j]=(old[i-1,j]+old[i+1,j]+old[i,j-1]+old[i,j+1])/4`。
- MPI 的 halo/ghost 行是其他进程的数据副本，不能当成固定物理边界。

**建议初版 MPI 采用一维按行分区，等 B 确认。** 对 rank r（从 0 起），设 `q=n//P`、`s=n%P`，本地内部行数为 `q+(r<s ? 1 : 0)`，首个全局内部行号为 `1+r*q+min(r,s)`。

例如 n=7、P=4：各进程拥有 2、2、2、1 行，起始全局行号为 1、3、5、7。建议首版要求 P≤n；P>n 时明确拒绝，暂不要求支持零内部行进程。是否支持二维分区留作后续设计，不能在当前稿中记为已经确定。

## 3. 命令行、停止规则和输出

统一调用形式：

```text
jacobi_executable n max_iters tolerance
```

1. `tolerance>0`：每轮根据**所有内部点的全局最大更新量**判断 `max_update<=tolerance`，满足才停。MPI 不能让某个进程按本地更新量单独退出。
2. `tolerance=0`：严格运行 K=`max_iters` 轮，不提前停止。此时 `max_error` 不要求达到收敛阈值。
3. 输出状态沿用 `fixed_iterations`、`update_tolerance_reached`、`iteration_limit`。程序完成返回 0，参数/运行错误返回 1，未达到正容差而耗尽轮数返回 2。MPI 启动器自身的退出值另行保存，不能仅凭其值替代结果验收。

程序 stdout 只输出一条 JSON；MPI/混合版本由 rank 0 输出，调试信息放 stderr。现有字段保留原名：

| 字段 | 统一定义 |
|---|---|
| `mode` | serial / openmp；未来 MPI/混合实现使用 mpi / hybrid |
| `n`、`tolerance` | 与输入一致 |
| `threads` | 每进程实际使用的线程数；初版要求各 rank 一致；串行为 1 |
| `iterations` | 已完成的更新轮数 |
| `max_update` | 最后一轮内部点的全局最大绝对改变量 |
| `max_error` | 最终内部点与精确解 x+y 的最大绝对误差 |
| `residual_inf` | 最终内部点的 `max(abs((4u-上下左右)/h²))` |
| `boundary_error` | 最终物理边界相对于规定边界值的最大偏差 |
| `compute_seconds` | 第 4 节定义的迭代阶段耗时 |
| `grid` | n≤8 必须输出含物理边界的完整全局网格，按 i 行、j 列排序 |

MPI 版本的误差、残差和边界指标都取全局最大值。最终残差计算必须使用最终轮的有效邻居数据，不能使用过时 halo。建议 MPI/混合版本额外输出 `mpi_processes`、`nodes`；这两个字段当前串行程序还没有，实现及实验记录须明确区别。

`max_iters`、完整命令、源码 SHA-256/commit、编译器和 flags、P/T、分配资源、作业 ID、绑定方式及重复编号由运行记录保存；现有 C++ JSON 不必为了这份建议立即改字段。

## 4. 计时和正确性口径

迭代计时包含更新循环、必要的边界通信、停止检查、OpenMP 同步。MPI 在同步起点后分别计时，最终报告最慢 rank 的耗时。初始化、最终误差/残差检查、最终网格收集和输出不计入迭代时间；如需端到端耗时则另设字段。PBS 排队时间、初始化模块和编译时间不当作 `compute_seconds`。

收敛模式每轮需要全局最大更新量用于统一停机；固定轮数模式只要求最后一轮输出正确的全局更新量，可避免每轮用于停机的全局归约。实际采用的归约策略须记录，设计比较不能混合不同策略后归因于进程/线程配比。

| 验收项目 | 推荐数值 | 范围与注意事项 |
|---|---|---|
| 正容差停止条件 | `max_update<=1e-12` | 是更新量，不是真误差或残差 |
| 小规模收敛精确解误差 | `max_error<=1e-8` | 适用于本版 n≤32 的收敛案例 |
| 小规模收敛离散残差 | `residual_inf<=1e-7` | 适用于本版 n≤32 的收敛案例 |
| 物理边界误差 | `boundary_error<=1e-14` | 当前串行实测为 0 |
| 小网格固定轮数对比 | 全网格最大绝对差≤`1e-12` | 与独立参考/串行对比，先检查网格形状与顺序 |

**这些误差阈值不能机械套到大规模固定轮数性能案例。** 更大 n 下相同更新量容差不意味着相同的真误差。本版不宣称 `1024 1000 0` 已求得收敛解；它测量的是相同 1000 轮工作的耗时。

固定轮数案例要求轮数完全一致；收敛案例的参考轮数用于定位问题，最终以停止状态、更新量、真误差和残差验收，不要求跨平台末位浮点数完全相同。
