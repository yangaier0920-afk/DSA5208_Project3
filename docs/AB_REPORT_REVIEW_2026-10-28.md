## 统计与正确性备查

| 证据 | 数量与边界 |
|---|---|
| 四套原验证 | 352数值、16拒绝；其中172次完整小网格独立参考 |
| 非对称 | 31次完整网格：7串行、24 MPI；最大差8.881784197001252e-16 |
| 非对称n7/tol=1e-12 | 7配置均330轮；解析误差1.2454925979454856e-11，残差2.519300323911011e-10 |
| 等待诊断验证 | 45次：18生产、27诊断；35全网格、10仅全局指标；最大逐点差2.220446049250313e-16 |
| 原x+y诊断n7/tol=1e-12 | 5配置均324轮；解析误差1.1444623027045964e-11，残差2.3145219074649503e-10；不混用330轮 |
| 结构化验证总数 | 428数值、16拒绝，238全网格是数值执行子集；额外verify_small串行前检不计入 |
| 正式扩展性能 | 四作业/五数据集/45配置：405正式+45预热=450次 |
| 独立诊断性能 | 9配置：45正式+9预热=54次；没有串行性能基准 |
| 性能合计 | 450正式+54预热=504次，全部保留 |
| 绑定 | 1501884为780条；1502229为673条，其中验证205、性能468；是执行前快照 |
| 归档 | 七份完整包；上次最终验收逐成员2271文件；1498804完整包仍缺，不在七份中 |

残差是含1/h²缩放的离散Laplace残差无穷范数，h=1/(n+1)；它、解析误差、最大更新量是不同指标。达到更新量阈值不等于残差达到同一数值阈值。1024/2048固定1000轮后约1.859/1.925解析误差不支持收敛宣称。

历史2048/P2生产SR到OV中位数之比降低为16.61%（1500222）和14.01%（1501884）；诊断SR到OV为0.62%，IM到OV为−0.17%。对照不同，不可替换。中位数之比降低与同轮降低的中位数也不同：2048/P12诊断IM到OV分别约1.00%和0.31%，均不是“隐藏通信比例”。

CV修复只涉及三个跨Python末位差异，最大2.22e-16；仅CV比较设rtol=1e-12、atol=1e-14，其他原始JSON/耗时/样本/中位数/min/max/方案比较仍精确核对。没有算法错误、原件修改或因此重跑，见[修复记录](../evidence/mpi_wait_audit_tool_fix_2026-10-28/analysis.md)。
